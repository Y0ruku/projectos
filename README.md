# projectos
# File System Simulator

โปรแกรมจำลองระบบจัดการไฟล์และการจัดสรรพื้นที่ดิสก์ (File System Simulator)  
จัดทำขึ้นเพื่อศึกษาแนวคิดเกี่ยวกับระบบไฟล์และการจัดการพื้นที่จัดเก็บข้อมูลในระบบปฏิบัติการ

## 🛠️ เทคโนโลยีที่ใช้

- Next.js
- TypeScript
- React
- Tailwind CSS
- Node.js
- npm

---

- Node.js
- npm
- Git
